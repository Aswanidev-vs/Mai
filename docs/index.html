Capabilities

Everything your code review needs

Auto PR Review

Every push triggers a deep code review. Bugs, style issues, security concerns — caught before human review.

Conflict Resolution

Detects merge conflicts and attempts auto-resolution. Pushes fixes as commits for your review.

Auto-Fix

Fixes formatting, imports, unused variables, and simple bugs. Commits directly to your PR branch.

Slash Commands

Type /review, /fix, or /resolve in any PR comment for on-demand AI assistance.

Private by Default

Runs on GitHub Actions. Your code never leaves your repo. No external servers, no data collection.

Ask Mai

Comment /oc on any issue or PR. Mai reads the context and responds with actionable guidance.
