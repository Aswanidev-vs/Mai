# F2: Major frameworks and tools

## Findings

### [1] AutoGen is in maintenance mode; Microsoft Agent Framework is its enterprise successor
- quote: "AutoGen is now in maintenance mode. It will not receive new features or enhancements and is community managed going forward. New users should start with Microsoft Agent Framework."
- url: https://github.com/microsoft/autogen
- source_type: primary
- published: 2025 (ongoing maintenance mode)
- confidence: high

### [2] Microsoft Agent Framework (MAF) is the active successor, with 12.5k GitHub stars and multi-language support
- quote: "Microsoft Agent Framework (MAF) is an open, multi-language framework for building production-grade AI agents and multi-agent workflows in .NET and Python."
- url: https://github.com/microsoft/agent-framework
- source_type: primary
- published: 2025-2026
- confidence: high

### [3] CrewAI leads in community adoption with 56.3k GitHub stars and 100k+ certified developers
- quote: "CrewAI is the leading open-source framework for orchestrating autonomous AI agents and building complex workflows... With over 100,000 developers certified through our community courses."
- url: https://github.com/crewAIInc/crewAI
- source_type: primary
- published: 2024-2026 (active development)
- confidence: high

### [4] CrewAI's dual abstraction model combines Crews (autonomous agent teams) with Flows (event-driven workflows)
- quote: "CrewAI Crews: Optimize for autonomy and collaborative intelligence with role-based AI agents. CrewAI Flows: Build event-driven automations that combine precise workflow control, single LLM calls, and native support for Crews."
- url: https://docs.crewai.com/introduction
- source_type: primary
- published: 2025
- confidence: high

### [5] LangGraph is a graph-based orchestration framework with 38.3k stars, trusted by enterprise customers
- quote: "LangGraph is a low-level orchestration framework and runtime for building, managing, and deploying long-running, stateful agents... Trusted by companies shaping the future of agents—including Klarna, Uber, J.P. Morgan, and more."
- url: https://docs.langchain.com/oss/python/langgraph/overview
- source_type: primary
- published: 2024-2026 (active)
- confidence: high

### [6] OpenAI Swarm (21.9k stars) is deprecated; OpenAI Agents SDK (28.2k stars) is the production replacement
- quote: "Swarm is now replaced by the OpenAI Agents SDK, which is a production-ready evolution of Swarm. The Agents SDK features key improvements and will be actively maintained by the OpenAI team."
- url: https://github.com/openai/swarm
- source_type: primary
- published: 2024-2025
- confidence: high

### [7] OpenAI Agents SDK is provider-agnostic, supporting 100+ LLMs beyond OpenAI's own APIs
- quote: "The OpenAI Agents SDK is a lightweight yet powerful framework for building multi-agent workflows. It is provider-agnostic, supporting the OpenAI Responses and Chat Completions APIs, as well as 100+ other LLMs."
- url: https://github.com/openai/openai-agents-python
- source_type: primary
- published: 2025-2026
- confidence: high

### [8] AutoGen pioneered the event-driven agent architecture with layered design (Core, AgentChat, Extensions)
- quote: "The autogen framework uses a layered and extensible design. Layers have clearly divided responsibilities and build on top of layers below... Core API implements message passing, event-driven agents, and local and distributed runtime."
- url: https://github.com/microsoft/autogen
- source_type: primary
- published: 2024 (architecture established)
- confidence: high

### [9] OpenAI Agents SDK introduces Sandbox Agents for long-running tasks with persistent workspace state
- quote: "Sandbox Agents: Agents preconfigured to work with a container to perform work over long time horizons."
- url: https://github.com/openai/openai-agents-python
- source_type: primary
- published: 2025-2026
- confidence: high

### [10] LangGraph's core design mixes deterministic steps with LLM-driven agentic steps in a single graph
- quote: "One of LangGraph's core strengths is the ability to mix deterministic steps with LLM-driven agentic steps in a single graph. This lets you build bespoke workflows where parts of the logic are fully predictable and auditable while other parts are flexible and model-driven."
- url: https://docs.langchain.com/oss/python/langgraph/overview
- source_type: primary
- published: 2025
- confidence: high

### [11] Microsoft Agent Framework supports A2A (Agent-to-Agent) and MCP (Model Context Protocol) interoperability
- quote: "Microsoft Agent Framework 1.0 gives you enterprise-grade multi-agent orchestration, multi-provider model support, and cross-runtime interoperability via A2A and MCP."
- url: https://github.com/microsoft/autogen
- source_type: primary
- published: 2025-2026
- confidence: high

### [12] CrewAI's enterprise offering (AMP Suite) adds managed deployment, observability, and governance
- quote: "For organizations that need a commercial control plane around CrewAI, CrewAI AMP Suite adds managed deployment, observability, governance, security, and enterprise support."
- url: https://github.com/crewAIInc/crewAI
- source_type: primary
- published: 2025
- confidence: high
